# 1.3.1 — палитра листа персонажа PF2e

Меню использует CSS-переменные PF2e: `--bg`, `--text-dark`, `--sub`, `--primary`, `--secondary`, `--text-light` и `--color-border-divider`. При отсутствии переменных используются стандартные цвета PF2e: светлый тёплый фон, бордовый основной акцент и тёмно-синие кнопки.

Убраны отдельные сине-серые палитры и переключение по теме ОС. Если тема переопределяет общие переменные PF2e, изменения передаются меню. Произвольные CSS-оформления, действующие только внутри `.actor.sheet`, автоматически не копируются. Стили менеджера не меняют лист персонажа.

Вкладки, адаптивная компоновка, кеши, отложенная загрузка и игровые механики версии 1.3.0 сохранены. Новых ограничений количества явлений нет.

Проверки: 100 браузерных тестов с подменённой средой Foundry/PF2e, включая три новые проверки цветов; ESLint, форматирование, локализация и релизная структура. Визуальная проверка проводится на настоящем шаблоне вне Foundry. Полноценный мир Foundry не запускался.

## Обновление

Сделайте резервную копию мира. Для GitHub Desktop скопируйте содержимое исходной папки в корень репозитория, не заменяя `.git`. Для ручной установки остановите Foundry и замените файлы в `Data/modules/pf2e-dailies-apparition-fix` содержимым установочного ZIP. После запуска обновите клиент через Ctrl+F5.

Версия манифеста — 1.3.1. Адрес загрузки релиза начнёт работать после публикации GitHub Release `v1.3.1`; пакет сам ничего не публикует.
