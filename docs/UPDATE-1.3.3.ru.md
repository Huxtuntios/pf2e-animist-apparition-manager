# Версия 1.3.3 — уменьшенный шрифт менеджера

Изменена только типографика окна управления явлениями:

- Основной текст, вкладки и поля ввода: 14 px вместо 16 px.
- Названия явлений в карточках: 15 px.
- Имя персонажа и значение фокуса: 16 px вместо 18 px.
- Подписи, Знания, метки, счётчики и пояснения: 12 px вместо 14 px.
- Названия раскрытых заклинаний: 13 px.
- Размер областей нажатия кнопок остаётся не меньше 44 × 44 px.

Палитра листа PF2e, подсветка основных явлений и компактная компоновка 1.3.2 сохранены. Шрифт листа персонажа вне менеджера не меняется. Механики и загрузка не изменены.

Проверены ESLint, форматирование, локализация, манифест и 108 браузерных тестов с имитацией документов Foundry/PF2e. Выполнена визуальная проверка широкого/узкого окна и раскрытых разделов. Это не проверка в запущенном игровом мире.

Установка аналогична 1.3.2: исходный ZIP предназначен для переноса содержимого в клон репозитория GitHub Desktop; runtime ZIP — для замены файлов установленного модуля при закрытом Foundry. После обновления перезапустите Foundry и нажмите Ctrl+F5. Перед обновлением сделайте резервную копию мира. Публикация релиза в GitHub не выполнялась.
