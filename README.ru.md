# Pf2e Animist Apparition Manager

[English version](README.md)

Самостоятельный менеджер **анимиста Pathfinder 2e** для **Foundry VTT 14**. Привязывайте явления, следите за их заклинаниями, Сосудами и Знаниями, выбирайте основные явления, а пул фокуса и ночная очистка подстроятся сами - всё это на листе персонажа и в одном окне управления, без **PF2e Dailies**.

Модуль может стоять рядом с PF2e Dailies (для обрабатываемых им персонажей отключается только ежедневная настройка анимиста самого Dailies) и работает с **PF2e Avatars**.

> О найденных ошибках и пожеланиях пишите в [трекер задач](https://github.com/Huxtuntios/pf2e-animist-apparition-manager/issues).

## Требования

|              | Модуль                 | Примечания                                                                                                            |
| ------------ | ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Обязательно  | Foundry VTT 13 или 14  | Рассчитан на 14                                                                                                       |
| Обязательно  | Система Pathfinder 2e  | В версии 8.6 и новее Знания явлений выдаются через Rule Elements; в старых версиях используются предметы Знаний       |
| По желанию   | PF2e Dailies           | Остаётся рабочим для всего остального; для анимистов отключаются только его ежедневные настройки анимиста и странствующих черт |
| По желанию   | PF2e Avatars           | Заклинание Аватар предлагает формы основных явлений                                                                   |

## Установка

1. В Foundry откройте **Add-on Modules → Install Module** и вставьте адрес манифеста:
   `https://github.com/Huxtuntios/pf2e-animist-apparition-manager/releases/latest/download/module.json`
   Для конкретной версии возьмите манифест этой версии на [странице релизов](https://github.com/Huxtuntios/pf2e-animist-apparition-manager/releases).
2. Включите **Pf2e Animist Apparition Manager** в мире.
3. Откройте лист персонажа-анимиста, перейдите на вкладку **Заклинания** и нажмите **Управление способностями анимиста** вверху.
4. Привязывайте явления кнопкой **Привязать** или кнопкой **Привязать случайное явление** рядом с полем поиска.

Идентификатор модуля - `pf2e-dailies-apparition-fix`; под ним хранятся настройки, флаги и API.

## Что умеет модуль

- **Привязка.** Привязанное явление даёт свои заклинания (не выше наибольшего ранга, который персонаж может сотворить), свой Сосуд и свои Знания; недостающие записи «Заклинания явления» и «Заклинания Сосудов» создаются сами, дубликатов не бывает. Общее у нескольких явлений учитывается по счётчику: отвязывание одного явления оставляет то, что ещё даёт другое.
- **Кнопка сотворения.** У заклинаний записи «Заклинания явления» (кроме заговоров) одна кнопка сотворения с выбором ранга, которая вызывает обычный `cast()` PF2e. Если заклинание можно сотворить только на одном ранге (10-й ранг или слоты остались только на одном), оно творится сразу, без меню.
- **Основные явления.** Выбираются звёздочкой рядом с названием. Размер набора фиксирован: одно явление, а с Медиумом с 9-го уровня - два. Клик по звёздочке другого явления ставит его на место основного (при двух основных небольшое окно спросит, какое заменить); клик по звёздочке основного убирает его из набора. Автоматический выбор включается по желанию.
- **Список Сосудов.** Сосуд каждого настроенного явления в списке, но использовать можно только Сосуды основных явлений: остальные зачёркнуты и с отключённой кнопкой сотворения. Кнопка обмена в зачёркнутой строке и кнопка **Сменить основное явление** в заголовке списка выбирают другое явление.
- **Заклинания от классовых черт.** Находятся по точному id в компендиуме, добавляются раз в день вместе с остальными заклинаниями явлений и убираются вместе с чертой: Исцеление и Вред (Embodiment of the Balance), Аватар (Supreme Incarnation, он же даёт слот 10-го ранга на 19-м уровне), Звериная форма (Walk the Wilds), Воздушная форма (Wind Seeker) и Форма чудовища (Monstrous Inclinations). Заклинание выше наибольшего ранга записи ждёт, пока в записи появится слот под него.
- **Знания.** В PF2e 8.6+ каждое Знание - это Rule Element на черте явления: обучен, эксперт с 8-го уровня, мастер с 16-го; при повышении уровня обновляется. Названия Знаний распознаются по-английски, по-русски и в двойных названиях русского перевода вроде «Знания фей (Fey) Lore».
- **Классовые умения.** Каждое привязанное явление выдаётся умением Apparition Attunement (Animist Dedication, если у персонажа только оно), поэтому на листе оно показано вложенным в это умение.
- **Отказаться от контроля.** У персонажа с этой чертой появляется раздел для выбора постоянного явления. Оно привязывается сразу и снова после каждого ночного отдыха, сохраняется при применении профиля и при восстановлении вчерашнего набора, отмечено булавкой и не отвязывается, пока не выбрано другое.
- **Ночная очистка.** По `pf2e.restForTheNight` временные черты, записи, заклинания и Знания модуля удаляются после сохранения снимка набора за день. **Восстановить вчерашнее** возвращает его; **Очистить остатки** убирает только старые и осиротевшие данные, но никогда не текущий день.
- **Профили, диагностика, исправление.** Сохраните набор явлений и основных как профиль подготовки и примените позже; предпросмотр показывает, что произойдёт. **Диагностика** сообщает состояние персонажа, а **Исправить персонажа** пересобирает его одним нажатием.
- **Встроенный макрос.** Клиент ГМа один раз создаёт мировой макрос «Привязать/отвязать явление»; он открывает то же окно с панели быстрого доступа.

### Странствующие черты (Wandering Feats)

Для анимиста или любого персонажа со странствующей чертой окно показывает каждую такую черту вместе с **каждой странствующей классовой чертой анимиста того уровня, на котором она взята, и ниже**: черта, взятая на 14-м уровне, может стать чертой 2, 6, 12 или 14 уровня. Варианты берутся из набора черт PF2e, набора `pf2e-anachronism` и черт мира; черта, которая у персонажа уже есть, повторно не предлагается. Черта другого уровня, чем 6, 12 или 16 (самодельная), считается ближайшей из них снизу, поэтому она не выпадает из списка.

Некоторым странствующим чертам нужно настроенное явление определённого вида. Это требование написано только в описании черты, поэтому модуль хранит **список подходящих явлений для каждой черты**:

- Для черт системы список получается из таблицы Знаний, которые нужны каждой черте (по точному id в компендиуме; подойдёт любое из перечисленных): Blazing Spirit - Battlegrounds или Volcano; Roaring Heart - Mountain; Grudge Strike - Heraldry или Underworld; Shadows Within Shadows - Hunting или Underworld; Forest's Heart - Forest или Herbalism; Monstrous Inclinations - Forest или Ocean; Jester's Gambol - Circus или Fey.
- ГМ добавляет явления в список черты, убирает их или сбрасывает черту к значениям по умолчанию в **Configure Settings → Pf2e Animist Apparition Manager → Требования странствующих черт**.
- У самодельной странствующей черты подходящими считаются явления, отмеченные её ГМом (если ничего не отмечено, требования нет).

Черта, которая есть у персонажа, но ни одно из подходящих явлений которой персонаж не привязал, отмечается предупреждением. В списке переобучения такой вариант помечен ⚠ и недоступен (ГМу всё равно можно). Остальные предварительные условия не проверяются. Новая черта занимает место старой (то же расположение, уровень получения и выдавшее умение), старая удаляется, а запись в чате фиксирует замену.

В том же окне настроек ГМ может **создать свою странствующую черту**: название, значок, уровень, теги, описание и список отметок подходящих явлений. Она сохраняется как обычная классовая черта мира с признаками «Анимист» и «Странствующая».

### Пул фокуса

Максимум ведёт один Rule Element на Apparition Attunement (Animist Dedication, если у персонажа только оно); он пересчитывается при любом изменении привязанных явлений или набора основных:

- PF2e прибавляет 1 к максимуму за каждое фокусное заклинание, кроме заговоров, а каждый Сосуд - такое заклинание. Сосуды **неосновных** явлений вычитаются обратно правилом *subtract*: при трёх привязанных явлениях и одном основном максимум равен 1, при двух основных - 2.
- С **Circle of Spirits** ничего не вычитается: пул равен числу фокусных заклинаний или числу настроенных явлений, смотря что больше (не более 3), через правило *upgrade*. Набор основных не увеличивается.
- **Максимум вручную:** в окне есть поле **Максимум фокуса вручную** (*Задать* / *Вернуть автоматический расчёт*). Оно переопределяет автоматическое значение до сброса, хранится на персонаже и переживает ночной отдых.

### Кастомные явления

**Configure Settings → Pf2e Animist Apparition Manager → Управление кастомными явлениями** открывает редактор самодельных явлений. Кастомное явление - обычная черта мира со своим списком заклинаний, Знаниями и созданным Сосудом, поэтому в окне управления оно выглядит как любое другое. В редакторе есть свой выбор значка (файловый браузер Foundry или путь вручную), сохраняются ручные правки Сосуда, доступны копирование и импорт/экспорт JSON. При активном PF2e Avatars каждому кастомному явлению можно назначить одну из существующих форм Аватара анимиста.

## Работа рядом с PF2e Dailies

PF2e Dailies может оставаться установленным для всего остального. Для персонажей с Apparition Attunement или Animist Dedication модуль берёт работу на себя. Единственное, что он записывает в данные Dailies, - флаг «отключить эту ежедневную настройку» для персонажа: для анимиста Dailies (`flags.pf2e-dailies.disabled.dailies.animist`) и, для персонажа класса анимист, для его настройки странствующих черт. Привязанные строки, основные Сосуды и самодельные записи в Dailies не копируются: его код листа зачёркивал бы Сосуды, которых нет в его собственном списке, и предлагал бы кнопку переобучения, работающую с другим набором.

Прежнее значение каждого флага запоминается и возвращается, когда **Включить менеджер явлений анимиста** выключается. **Выключайте эту настройку до удаления модуля**: когда модуль уже не загружен, флаги восстановить нельзя. Персонаж, получивший Apparition Attunement или Animist Dedication во время игры, переключается сразу.

## PF2e Avatars

При активном `pf2e-avatars` заклинание Аватар анимиста предлагает формы основных явлений этого модуля. PF2e Dailies защищает свой API от изменений, поэтому модуль оборачивает собственный обработчик чата модуля Avatars в момент его регистрации и сам обрабатывает ветку анимиста; в `game.dailies` ничего не присваивается. Для кастомных Сосудов без подходящей формы остаются обычные варианты модуля Avatars. Если `pf2e-avatars` нет или он отключён, ничего не устанавливается.

## API

```js
const api = game.modules.get("pf2e-dailies-apparition-fix").api;
await api.addApparition(actor, apparitionItemOrUuid);
await api.removeApparition(actor, apparitionItemOrUuid, { silent: true });
api.openManageApparitions(actor);
```

- `addApparition(actor, apparition)` / `removeApparition(actor, apparition, { silent })`
- `openManageApparitions(actor)` / `openCustomApparitions()` / `openWanderingRequirements()`
- `getApparitionState(actor)` / `getPrimaryVesselState(actor)` / `setPrimaryVessel(actor, apparitionKey, isPrimary, { replaceKey })`
- `getFocusPointsOverride(actor)` / `setFocusPointsOverride(actor, value)`
- `getApparitionProfiles(actor)`, `saveApparitionProfile(actor, name, { id })`, `deleteApparitionProfile(actor, profileId)`, `applyApparitionProfile(actor, profileId)`
- `getLastDayApparitionSnapshot(actor)` / `restoreLastDayApparitions(actor)`
- `getPermanentApparition(actor)` / `setPermanentApparition(actor, apparitionUuid)` - выбор «Отказаться от контроля»
- `isAutoPrimaryEnabled()` / `setAutoPrimaryEnabled(enabled)`
- `diagnose(actor)` / `repairApparitionActor(actor)` (псевдоним `fixCurrentAnimist`) / `getManagedOrigin(item)`
- `syncDailiesIsolation(actor)` - заново отключить ежедневную настройку Dailies для персонажа-анимиста

Хуки, вызываются через `Hooks.callAll`:

| Хук                                               | Аргументы                                         | Когда                                                                |
| ------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------------------------- |
| `pf2e-dailies-apparition-fix:apparition-bonded`   | `actor, { key, apparition }`                      | Когда есть всё, что даёт явление; только для новой привязки          |
| `pf2e-dailies-apparition-fix:apparition-unbonded` | `actor, { key, apparition }`                      | После отвязки явления                                                |
| `pf2e-dailies-apparition-fix:primary-changed`     | `actor, primaryKeys`                              | Когда набор основных явлений действительно изменился                 |
| `pf2e-dailies-apparition-fix:rest-cleanup`        | `actor, removedCount`                             | После очистки при ночном отдыхе                                      |
| `pf2e-dailies-apparition-fix:apparition-repaired` | `actor, { repaired, removed, missing, warnings }` | После **Исправить персонажа**                                        |

## Известные ограничения

- Модуль встраивается в лист персонажа PF2e (вкладка заклинаний, кнопки сотворения, список Сосудов). Обновление системы, меняющее шаблон листа, может потребовать обновления модуля.
- Предварительные условия странствующих черт, кроме требования к явлению, не проверяются.
- Заклинания, Сосуд и Знания явления читаются из описания черты явления, поэтому самодельное явление сохраняет структуру, которую создаёт редактор кастомных явлений.

## Разработка

```
npm ci                      # установить инструменты разработки
npm test                    # линтер, форматирование, файлы локализации, проверка релиза
npm run format              # отформатировать скрипты и стили
npm run build:release -- --repo Huxtuntios/pf2e-animist-apparition-manager
```

Код - обычные ES-модули: без сборки, без `libWrapper`, без jQuery. `npm run build:release` создаёт `dist/module.json` и `dist/module.zip` - те же файлы, которые workflow релиза прикрепляет к релизу на GitHub. Публикация релиза описана в [docs/RELEASING.md](docs/RELEASING.md).
